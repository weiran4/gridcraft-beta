交流参考点

电流正方向：逆变器 → 电网；Park：d = cos、q = −sin；P = vd·id + vq·iq，Q = vq·id − vd·iq（pu）。电压测量点是 PCC / RC 支路端点，不是电容内部电压。图内滤波时间与上方联动。

采用并联形式 C(s) = Kp + 1/(Ti·s)，积分支路不乘 Kp；内部 Ki = 1/Ti。Kp 为 pu/pu，Ti 为秒。Ti 可填 ∞ 关闭积分。

当前成网模式的定义与分析范围

切换成网模式不会凭空改变相同电路下的内环 PI；本版不自动整定 H、D、下垂系数或励磁增益，也不验证三种模式的整体稳定性。Synchronverter 页面采用“转子 / 励磁 + 双环”的参考结构，不能直接代表所有实现。

03内环频响校核

电流环断开外电压 PI；电压环含已闭合电流环。

电网 R/L 与 RC 会改变内环对象。非零纯延时采用精确频域相位；有限阶 Routh 校核仅用于零延时。相位裕度不能代替完整 GFM 系统校核。

04计算依据

内环模型公式
Zb = VLL² / Sbase；ZL = Rf + sLf；Zc = Rc + 1/(sCf)；Zg = Rth + sLth
Zp = Zc·Zg / (Zc + Zg)；Hi = 1/(1+sTi,meas)；Hv = 1/(1+sTv,meas)
D = exp(−sTd)，Td = N·Ts；A = [ZL + (1 − av·D·Hv)·Zp] / Zb
Li = Ci·D·Hi / A；Ti,cl = (Ci·D/A) / (1+Li)
Gv = (Ti,cl·Zp/Zb) / (1 − F·Ti,cl·Zp/Zg)
Lv = Cv·Gv·Hv；Tv,cl = Cv·Gv / (1+Lv)

连续模型使用额定电压处的固定角度标量近似，不求解运行点潮流；P/Q 用于初始外环参考和运行电流校核。理想 dq 交叉解耦为模型假设；实际解耦、测量方向或 PI 输出极性不一致时不能直接照填。
