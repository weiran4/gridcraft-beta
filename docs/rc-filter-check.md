# RC 初选与谐波校核

入口：主画布选择 RC → RC 滤波设计。只在明确点击应用时写入元件 R/C；试选不会更改元件参数。设计输入沿用原有工程保存机制，谐波校核的频率、要求及网络对照为本次窗口的临时输入。原有 demo 不变。

## 分开回答三个问题

1. **电容与阻尼初选**：保留电容无功及局部 LC 频率区间。新设计以 QF=5 起步，保存的 QF 不迁移。Rc=√(Lf/Cf)/QF 是忽略 Rf 的局部近似，不是强制标准或闭环稳定保证。可切换为手动 Rc。
2. **无源网络谐波传递**：对比当前 R/C 与试选 R/C。默认读取当前网络，也提供仅保留选定逆变器 Lf/Rf 与本 RC 的空载对照。关注频率默认跟随开关频率，允许独立输入。传递比例要求由用户填写，不预设“合格纹波”。
3. **闭环稳定性**：此页未计算。应用后由相应 GFL/GFM 分析页校核，不把电容区间或单频通过呈现为整体设计通过。

## 解析计算

平衡每相网络中，关联桥侧单位电压谐波通过 Zf=Rf+jωLf 注入 RC 所在节点。其 Norton 等效电流为 1/Zf。将所有桥侧理想电压源及电网理想源的谐波置零后，用节点导纳矩阵求驱动点阻抗 Zdrive（包含关联逆变器的滤波支路）：

H(jω) = V_PCC,h / V_bridge,h = Zdrive(jω) / Zf(jω)。

复用现有网络折算与节点求解；包含连通 RL 支路、变压器变比和漏阻抗、RC 及其他逆变器的滤波支路。其他逆变器控制作用、背景电压谐波、寄生参数和独立负载均未建模。元件库目前没有独立负载元件，不能据此声称完成带任意负载的实际系统校核。

局部空载且 Rf=0 时，解析结果退化为：

H(s) = (1+sRcCf)/(1+sRcCf+s²LfCf)。

曲线以物理频率 Hz 表示，不是 dq 控制环频率响应。幅值显示 20log10|H|；5% 传递比例约为 −26 dB，不能等同于 5% 额定电压纹波或 THD。绝对纹波及高频电阻损耗还需要输入谐波频谱。单频通过不保证整个频带通过；离散绘图点也不保证捕捉极窄峰值。

若 RC 接入点直接接理想电压源，H=0；这不代表谐波电流为零。理想无损谐振点的导纳抵消按原始支路尺度判定数值奇异，避免将浮点残差当成可信有限结果。
