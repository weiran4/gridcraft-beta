# PCC 频率响应预览

入口：电路中标记为 PCC 的母线参数面板，或 PCC 分析栏的“PCC 频率响应”。计算在浏览器完成，不注入时域扰动。

- 上游电网：Rth + jωLth，频率为电气频率。
- 无源网络：源置零后的节点导纳求解，包括滤波支路及变压器折算。
- 受控变流器：同节点单变流器端口 dq 导纳，电流正方向为流入变流器端口；频率为同步 dq 坐标系中的扰动频率。

GFM 使用已保存的 PI 和当前成网模式，在工作点数值线性化，计算 C(jωI−A)⁻¹B+D，再转换为 SI 导纳。提取端口时移除上游电网动态；上游参数仍参与工作点计算。支持 Droop、Synchronverter、VSG 当前模型。

GFL 本版使用固定同步角、冻结外环和理想电流解耦近似，包含内环 PI、测量滤波、延时及 RC 支路。未包含 PLL 和外环动态，不能据此宣称完整弱网稳定性。

页面读取已保存的 PI，不自动重整定。电路和 PI 跨页变更会重新计算；扫频范围保存在对应 PCC 元件。支持通道开关、频点读数和 CSV 导出。奇异频点断线，零幅值不画 dB；曲线本身不自动给出稳定性结论。

验证包括解析 RL 对照、无源节点模型对照，以及三种 GFM 模式端口重新连接电网后复现原完整模型频率响应。
