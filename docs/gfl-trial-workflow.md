# GFL 联立模型的精算与试验 PI

标准范例、电气参数和控制方程不变。

- 完整外环极点判定稳定性；时域数值质量表示响应计算是否完成；推荐条件还包括用户设置的性能与频域限制。这三个结论分别显示。
- 响应采样预算默认 20,000 点，可选 60,000 点继续精算。不放宽误差容限；采样不足不能等同于不稳定。
- 附加标量相位裕度约束默认开启。关闭仅取消这一附加门槛，不取消完整模型稳定性、时域计算或其他目标检查；标量裕度不是完整 dq 系统裕度。自动搜索的种子策略未在本次改动中扩展。
- 勾选声明后可保存手动草稿为试验 PI。该操作不授予校核达标状态，保留一步恢复记录，不改电气参数。工程变化后旧草稿不得覆盖新工程。

## 本地复核

PV 范例，SCR 电网模型，SRF PLL 20 Hz，阻尼 0.7071067811865476，PLL 独立滤波 0 ms，Ts 50 μs，显式延时 0。

| 环路 | Kp | Ki / s⁻¹ | Ti / s |
|---|---:|---:|---:|
| d 电流 | 2.2 | 800 | 0.00125 |
| q 电流 | 2.2 | 800 | 0.00125 |
| Vdc | 0.75 | 3 | 0.3333333333 |
| Vac | 0.06 | 15 | 0.0666666667 |

并联式 PI：C(s)=Kp+Ki/s，Ti=1/Ki。

60,000 点预算下完整模型最大极点实部约 −4.92722 s⁻¹。Vdc 超调约 23.0247%，±2% 稳定时间约 0.526214 s；Vac 约 2.05676%、0.337391 s。

默认 60° 附加标量裕度条件仍不满足。关闭该附加条件且不另设超调/稳定时间上限时，这组参数通过当前模型的推荐条件；这不是 EMT、限流或硬件稳定性验证，也不是对原始范例参数的替换。
