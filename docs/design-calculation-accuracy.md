# 数值计算口径与验证

本项目使用 SI 单位计算，界面转换为 kV、MVA、mH、μF。显示时取整不回写到计算输入。以下为公式、假设和可复现实例。

## 电容无功约束

平衡三相、每相电容 Cf：`|Qc| = ω Cf VLL²`，故 `Cf,max = δQ Prated / (2π f0 VLL²)`。这里 VLL 为线电压 RMS，Qc 是三相无功幅值。忽略阻尼电阻对基波无功的影响。

对 Prated=1 MW、VLL=315 V、f0=50 Hz、δQ=5%，上限为 1603.980278 μF。选用每相 1500 μF 时无功占比为 4.675868%。计算直接使用线电压，不对相电压做中间取整。

## 电感谐波约束

相电压和线电压谐波峰值均以 Vdc/2 为 pu 基准。平衡非零序谐波满足 `Vh,LL,pk = √3 Vh,ph,pk`；共模/零序分量不使用此换算。

`Lmin = vh,ph,pu Vdc / (2π fh δi Idesign)`。

若输入为线电压 pu，则分母额外乘 √3。切换口径时同步换算 pu，保持物理幅值及计算结果不变。δi 是谐波电流峰峰值与所选 RMS 电流之比，fh=h f0。

PWM FFT 根据参考波与三角载波直接生成开关状态，再提取频谱；默认三次谐波注入比例可编辑。频率窗口采用整周期条件，有限采样结果不代表含死区和器件压降的设备频谱。主导纹波判断按谐波电压幅值除以频率比较，而不是只选最大电压柱。

## 设计电流

`Ibase = Srated/(√3 VLL)`；`Iop = √(P²+Q²)/(√3 VLL)`；`Idesign = kI Ireference`。

额定/运行电流由用户明确选择，kI 是设计裕量。不能将给定 AC 侧 P/Q 对应电流的设计裕量自动解释成变流器效率。DC 电容的效率参数用于其能量估算，含义不同。

## 桥侧电压与调制

`Vph=VLL/√3`，`Xf=2πf0Lf`。

`Vcon,ph,rms ≈ √[(Vph+XfQ/(3Vph))²+(XfP/(3Vph))²]`；`m=2√2 Vcon,ph,rms/Vdc`。

这是给定端电压下的简化稳态关系，忽略滤波电容基波电流和电感电阻压降，并非全网潮流解。

## 变压器标幺阻抗

选择绕组的基准阻抗为 `Zbase=VLL²/Srated`。`R=Rpu Zbase`，`X(f)=Xpu Zbase f/fbase`。跨理想变压器折算阻抗乘变比平方；额定容量和基准频率必须明确。

## 实现与复核

计算位于 analysis/ 与 core/electrical/；对应单元测试覆盖单位换算、数值边界、相/线等价性和输入联动。使用 `npm test` 复核。PI 的独立状态空间比较见 validation/pi-comparison.md。
