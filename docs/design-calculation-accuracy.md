# 设计计算精度与参数口径核对

日期：2026-10-03  
用途：项目开发与计算核对记录，不作为产品界面的展示文案。

## 1. 结论与适用范围

我们的改进主要是：严格使用输入参数、避免中间取整、明确相/线电压和峰值/RMS 的口径，并让计算随运行工况联动。这些能够提升计算的一致性和可追溯性，但不能据此宣称整个物理模型比参考资料更准确。

下文中的 1 MW、1 MVA、315 V 等数值是固定的对照算例，不代表用户当前工程中的实时参数。

| 核对项目 | 已确认的改进 | 结论边界 |
| --- | --- | --- |
| AC 电容无功上限 | 直接使用 315 V 线电压，避免先将相电压近似为 181 V | 准确结果为 1603.98 μF；参考表为 1619.0 μF |
| 电容无功占比 | 用相同的准确电压计算上限与选值校核 | 1500 μF 对应 4.6759%，参考表为 4.63% |
| 电感谐波幅值 | 区分相电压和线电压 pu，切换时同步换算数值 | 避免重复除以 √3 或漏除 √3 |
| 电感下限 | 区分 0.389 的精确代入与 0.4 的近似代入 | 约 0.065 mH 与 0.067 mH 来自不同输入，不能强行统一 |
| 设计电流 | 区分额定电流、P/Q 运行电流与设计裕量倍率 | 不再将经验倍率解释成确定的变流器效率 |
| 桥侧电压与调制比 | 使用运行 P/Q 和滤波电感计算并联动 | 属于工况一致性改进，仍为简化稳态模型 |

## 2. AC 电容：已确认的数值精度差异

### 2.1 公式与输入

忽略阻尼电阻对基波无功的影响，平衡三相、每相电容为 Cf 时：

```text
|Qc| = 3 × ω0 × Cf × Vph² = ω0 × Cf × VLL²
|Qc| ≤ δQ × Pcon
Cf,max = δQ × Pcon / (2π × f0 × VLL²)
```

这里的 Qc 为三相电容无功的幅值，Cf 为每相电容，不是三相电容数值之和；Pcon 为额定有功。

| 变量 | 对照值 |
| --- | --- |
| Pcon | 1,000,000 W |
| VLL | 315 V RMS |
| Vph = VLL / √3 | 181.8653348 V RMS |
| f0 | 50 Hz |
| δQ | 5% = 0.05 |
| 所选 Cf | 1500 μF / 相 |

严格代入：

```text
Cf,max = 0.05 × 1,000,000 / (2π × 50 × 315²)
       = 0.001603980278 F
       = 1603.980278 μF

|Qc| = 2π × 50 × 1500×10⁻⁶ × 315²
     = 46,758.679658 var

|Qc| / Pcon = 4.67586797%
```

### 2.2 表格中的 1619.0 μF 与 4.63% 怎样复现

若改用 Vph = 181 V，则：

```text
Cf,max = 0.05 × 1,000,000 / (3 × 2π × 50 × 181²)
       = 1619.353735 μF

|Qc| / Pcon = 3 × 2π × 50 × 1500×10⁻⁶ × 181² / 1,000,000
           = 4.63147726%
```

这两个结果同时与表格高度吻合，因此支持“该部分计算使用了约 181 V 相电压”的推测。但资料没有说明这个中间值的来源，不能断言作者具体如何取整或是否录入有误。315 V 对应的准确相电压为 181.865 V，表中列出的相电压则为 182 V。

另外两列用额定线电压 690 V 直接计算，2.5 MW 和 0.75 MW 分别得到 835.722 μF、250.717 μF，能复现表中的 835.7 μF、250.7 μF。这进一步支持公式本身一致、PV 列数值输入存在差异的判断。

### 2.3 与谐振约束合并

对 Lf = 0.063 mH、f0 = 50 Hz、fsw = 2000 Hz：

```text
500 Hz ≤ fres ≤ 1000 Hz
Cf,res,max = 1 / [(2π × 500)² × 0.063×10⁻³]
           = 1608.272756 μF
```

因此，采用准确的 315 V 时，最终电容上限是：

```text
Cf,max,final = min(1603.980278, 1608.272756)
             = 1603.980278 μF
```

选用 1500 μF 仍满足无功及谐振两项约束。工具不应为了得到 1619.0 μF 而修改公式或加入拟合系数。

## 3. 电感：相电压与线电压谐波口径

### 3.1 同一物理谐波的两种表示

两种 pu 都以 Vdc / 2 为基准。对这里用于纹波设计的平衡三相非零序谐波：

```text
Vh,LL,pk = √3 × Vh,ph,pk
vh,LL,pu = √3 × vh,ph,pu
```

因此：

```text
相电压形式：Lmin = vh,ph,pu × Vdc / (2π × fh × δi × Idesign)
线电压形式：Lmin = vh,LL,pu × Vdc / (2√3π × fh × δi × Idesign)
```

相电压系数已是每相值，不应再除 √3。切换相/线口径时必须同步转换 pu，才能保持物理幅值和电感结果不变。零序/共模谐波不适用上述非零序幅值换算，不能直接作为同一种差模纹波激励。

### 3.2 本次独立执行项目 FFT 的核对结果

设置：理想两电平 SPWM、50 Hz 基波、2000 Hz 三角载波、15% 三次谐波注入，一个基波周期采样 262144 点。调制参考为：

```text
vref,a = m × [sin(ω0t) + 0.15 × sin(3ω0t)]
```

| 调制比 m | 检查次数 h | 相电压峰值 pu | 线电压峰值 pu | 表格系数 |
| --- | --- | --- | --- | --- |
| 0.643 | 79 | 0.388519 | 0.672991 | 0.389 |
| 0.939 | 38 | 0.206338 | 0.357375 | 0.206 |

在这些调制假设下，FFT 支持将表格系数解释为相电压谐波峰值 pu。FFT 是有限采样下的理想波形计算，不代表实际设备包含死区、器件压降和控制动态后的实测频谱。

### 3.3 为什么 0.065 mH 与 0.067 mH 都会出现

固定对照输入：Vdc = 800 V，Idesign = 1928 A，δi = 10%，h = 79，f0 = 50 Hz。

```text
N = fsw / f0 = 2000 / 50 = 40
h = 2N − 1 = 79
fh = h × f0 = 79 × 50 = 3950 Hz
```

| 相电压谐波系数 | 计算方法 | Lmin |
| --- | --- | --- |
| 0.389 | 正确的相电压形式 | 0.0650363 mH |
| 0.4 | 正确的相电压形式 | 0.0668753 mH，保留三位小数为 0.067 mH |
| 0.389 | 错误地额外除以 √3 | 0.0375487 mH |

0.4 能复现表格结果，但只能证明一种可能的近似输入，不能证明作者确实采用了 0.4。工具应显示真实输入对应的结果，不以贴近表格数值为目标。

## 4. 电流：口径更清楚，但 1928 A 的来源仍待确认

额定容量电流与运行电流分别为：

```text
Ibase = Srated / (√3 × VLL)
Iop = √(P² + Q²) / (√3 × VLL)
Idesign = kI × Ireference
```

其中 Ireference 由用户选择额定电流或运行电流，kI 是明确的设计裕量倍率。

对 1 MVA、315 V：Ibase = 1832.858 A。对 P = 1 MW、Q = 0.5 Mvar、315 V：Iop = 2049.198 A。因此，增加无功确实增加运行电流，但这个工况并不等于 1928 A。

此前将 1832.858 A 除以 0.95 得到 1929.324 A，仅说明某个修正比例能贴近 1928 A，不构成效率推导。反过来，假设 P = 1 MW、VLL = 315 V，1928 A 对应约 0.32636 Mvar 无功；这也只是反算可能性，不是参考算例实际无功的证据。

实际变流器效率涉及输入输出有功损耗，不能在没有明确功率测量侧、功率因数和电压条件时，直接拿来修正已给定交流 P/Q 对应的电流。工具中的设计电流倍率与 DC 母线电容设计的变流器效率 η 应保持不同含义。

## 5. 运行点联动：提高一致性，不夸大模型精度

工具按运行 P/Q、额定交流电压和已应用的滤波电感计算：

```text
Vph = VLL / √3
Xf = 2πf0Lf
Vcon,ph,rms ≈ √[(Vph + XfQ/(3Vph))² + (XfP/(3Vph))²]
m = 2√2 × Vcon,ph,rms / Vdc
```

桥侧电压和调制比随运行点联动，而不是固定沿用某个表格中的 0.206 kV。额定容量与运行视在功率仍应区分；电容无功限值的分母也仍是约定的额定有功，不能随意换成运行 P。

当前桥侧电压模型忽略滤波电容基波电流和滤波电感电阻压降，采用给定端电压，不是全网潮流求解。FFT、局部 LC 谐振和被动网络谐振各有自己的模型假设；本记录不意味着已验证完整控制系统稳定性。
