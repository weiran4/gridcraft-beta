# 输入值来源显示

本次只增加数值来源提示、灰色建议样式和恢复建议操作；不精简功能，不改计算方程、demo 数值或已有工程的有效参数。

- 建议值：仅当输入使用明确的现有初始假设时显示灰色，并标注“建议值 · 当前采用”。数值在 input.value 中，直接走原有读取及计算流程，非 placeholder 隐含默认。
- 自定义：用户输入后以深色显示。即使用户输入值与建议相同，也不推断为未经修改的建议。
- 已保存值：旧工程没有来源记录时保留这一身份，不因数值恰好等于默认值而重新标成建议。
- 来自工程 / 跟随工程 / 自动计算：分别表示工程初值、联动输入和解析生成值。它们不是通用推荐值。
- 空白：保留缺失或未设限语义，不补造硬件参数、PI 增益、验收门槛。清空必填项仍走原验证逻辑。

建议数值沿用各窗口原来的默认定义，不新增数值策略。恢复建议按钮走正常 input/change 事件，执行原有校验和计算；设计窗口仍需明确应用才改变物理元件。PI 页原有自动保存流程保持不变。

来源记录使用 `_inputSources` 扩展，以显示值核对记录是否仍有效；其他页面或外部导入修改数值后，失配的旧记录不会继续把它显示为建议。整定目标的来源记录与数值 request 分开，避免表示状态进入模型请求及快照。PLL 沿用已有 sources 机制。

覆盖 Lf、RC、DC 电压、DC 电容窗口，GFL/GFM 参数及整定目标，GFL 主线 PLL 数值和独立 GFM 结构诊断草稿。尚无可信初值的参数继续要求明确输入；本次不为 PI 生成固定推荐增益。

验证：`tests/input-sources.test.js` 校验来源规则；`tests/browser/input-sources.html` 在独立浏览器配置中验证四种设计窗口、GFL/GFM 编辑、恢复、保存重载，以及物理参数和未配置 PI 保持不变。后者会替换测试浏览器的 localStorage，请不要在个人工作配置中运行。
