# PV Grid 示例参数

三相平衡单机模型，供功能演示与回归测试使用。所有参数都可以在工具中编辑。

- 基波：50 Hz；电源线电压：220 kV。
- 电网串联支路：R=2303.01 Ω，L=41.568 H。
- 两级变压器：220/35 kV、35/0.315 kV；默认完整范例容量各 1 MVA，Rsc=0.001 pu，Xsc=0.1 pu，基准 50 Hz。
- GFL：额定 1 MVA、1 MW，线电压 315 V，运行 P=1 MW、Q=0。
- 逆变器支路：Rf=1 μΩ，Lf=63 μH；DC 电压 800 V。
- 每相串联 RC：R=0.051 Ω，C=1500 μF。
- PI 模式：Vdc / Vac；独立分析电容 64000 μF；控制步长 50 μs，等效延时 0。
- P/Q、直流电压、交流电压滤波各 10 ms；电流滤波 1 ms。

完整默认范例由 examples/pv-grid-demo.js 定义。部分单元测试使用额外简化网络或理想变压器，应以该测试的输入为准。

SCR 用所选 PCC 的上游等效阻抗及逆变器额定容量计算，不包含 RC、逆变器 Rf/Lf 或 DC 支路。PI 内环使用逆变器 Rf/Lf；Vac 的静态灵敏度使用同一交流节点上游电抗。两种模型的分析范围不同。
