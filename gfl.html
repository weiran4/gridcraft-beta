控制结构

选中元件专属参数 · pu

滤波模块显示 1/(1+sT)，框内 T（ms）可直接编辑，并与上方测量滤波双向同步；输入 0 为旁路。它不同于计算 / PWM 纯延时 exp(−sTd)。
并联式 PI：u = Kp·e + (1/Ti)∫e dt。Ti 单位为秒，积分支路不乘 Kp；Ti 越小积分越强，输入 ∞ 可关闭积分。外环可选 P/Vdc 与 Q/Vac；不叠加参考前馈。Vdc、Q、Vac 的控制极性通过 −1 单独施加，PI 增益保持非负。拖动滑块直接更新下方频率响应。

电流方向与 dq 符号约定

本页采用 d = cos、q = −sin 的幅值不变 Park 变换，电流正方向为逆变器 → 电网，P/Q 以注入电网为正。电流误差为给定 − 滤波测量，电压指令中的 PI 输出取正号；d 轴解耦 −ωLiq，q 轴解耦 +ωLid。

若仿真电流方向为电网 → 逆变器，最直接的对接方式是在进入本控制器前同时反转 id、iq，功率测量也统一为注入方向。若保留反向电流坐标，则电流 PI 输出取负号，d/q 解耦分别改为 +ωLiq / −ωLid，电流给定也要反号。在 P/Q 仍以注入为正时，外环输出极性 P 为负，Q/Vdc/Vac 为正。电压前馈仍为正。

仅反转坐标且保持相同标幺基准、滤波与 PI 定义时，Kp、Ti 的数值不变；符号未同步会导致正反馈。若 q 轴方向、功率定义或标幺基准不同，还需转换。此处 Ti 对应 Kp + 1/(Ti·s)；若目标采用 Kp·(1+1/(Ti·s))，其 Ti 应填写 Kp × 本页 Ti。

连续时间 PI + 所选电气对象 + 等效纯延时 exp(−sTd)，频率上限 fs/2。开环包含对应测量滤波，闭环显示所选实际输出 / 给定。Vdc 引入电容能量动态，Vac 引入电网静态电压灵敏度。电流环采用理想 dq 解耦，忽略滤波解耦残余。交流电压滤波同时用于 Vac 反馈和电压前馈；未勾选 SCR 时采用本地 RL 模型；勾选后电网与 RC 的标量动态、滤波电压前馈参与给定跟踪。不含 PLL 或完整 dq 弱网耦合；多次交越或内环不稳定时不能仅凭一个相位裕度判断稳定性。零延时可计算小信号线性阶跃指标；不运行开关 EMT。
